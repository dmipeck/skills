# Jev Triage

Classify open issues with the triage queue label via Jev Choice questions
(`category`, `state`), then apply labels when both confidences meet the
threshold.

```bash
python skills/dmipeck/jev-triage/scripts/triage.py \
  --provider github \
  --project OWNER/REPO \
  --min-confidence 0.8
```

| Flag | Notes |
| --- | --- |
| `--provider` | `github` \| `gitlab` \| `gitea` (required) |
| `--project` | `OWNER/REPO`; GitLab also accepts numeric id / URL-encoded path |
| `--min-confidence` | `0`–`1`; both Choice confidences must meet it to write |
| `--dry-run` | classify + print only; **no** label/comment writes |
| `--base-url` | self-hosted GitLab/Gitea API root |
| `--label` | queue label (default `needs-triage`) |
| `--limit` | max open issues |

**Writes are on by default.** Prefer `--dry-run` until thresholds look right.

Env: `TYPESAFE_API_KEY` required. Forge auth via existing CLI login
(`gh` / `glab` / `tea`). Needs `typesafe-sdk` installed.

On apply: add category + state labels, remove the queue label, comment
starting with `> *This was generated by AI during triage.*`. Below
threshold: leave the queue label, print skip reason.
